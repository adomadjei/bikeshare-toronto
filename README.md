# bikeshare-toronto
Bike share allows for users to find the bike they want or finding available docs when they need to return.

This dashboard allows for real time interaction tracking WEB app. This solves these exact challenges by allowing users to check real time bike and dock availability, visualise station locations on an interactive map color coded by bike availability and helps users find the nearest stations to rent or return a bike based on their exact locations.

Impact of this project
- Bike share operators can improve their operational transparency
- enhance user satisfaction
- increase the efficiency of station management
- For users it eliminates frustration and helps them to plan their trips better
